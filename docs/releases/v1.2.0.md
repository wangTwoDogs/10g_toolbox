# 二狗叔叔的工具箱 1.2.0

新增录音批量压缩，并优化大体积 WAV 录音的处理。原有视频转音频功能继续保留。

## 更新内容

- 一次选择多份录音，选择保存文件夹后在后台依次压缩；单份失败后继续处理下一份。
- 保存处理记录，支持按状态筛选、失败重试、试听及勾选多个结果后分享。完成一份就能使用，无需等待整个队列结束。
- WAV / PCM 直接编码，绕过多余的原始音频解码器；离线压缩优先使用系统软件 AAC 编码器。
- 适合人声的有损压缩：M4A（AAC）、单声道、32 kbps、采样率最高 16 kHz，每小时约 14 MB。
- 保留原录音和完整时长，不裁剪、不分段、不自动上传；停止队列时保留已完成文件，仅清理本次创建的未完成文件。

## 安装

在本页 Assets 中下载 **ErgoushushuToolbox-1.2.0.apk**。支持 Android 8.0 及以上，可覆盖安装旧正式版，发布签名保持一致。

如果安装的是早期 debug 测试版，需要先卸载测试版，再安装正式版。

## 验证

- 18 项安卓设备测试、9 项 JVM 单元测试通过；调试与正式构建及 Lint 检查通过。
- API 35 模拟器测试：95 分 37 秒、约 1 GB 的合成 WAV，处理用时约 2 分 52 秒，输出约 22 MB，时长校验通过。
- 上述为模拟器与合成信号数据，实际手机耗时取决于设备和文件；尚未在一加 12 / ColorOS 16 真机验证旧版卡住问题。
